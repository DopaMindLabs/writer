# ඔබේ දත්ත

මෙම යෙදුම **දේශීය-ප්‍රථම** ය: ඔබේ ලිවීම ඔබේ බ්‍රවුසරයේ, ඔබේ ම උපාංගයේ ගබඩා කෙරෙයි. Server එකකට කිසිවක් upload නොකෙරේ, සහ යෙදුම සම්පූර්ණයෙන්ම offline ක්‍රියා කරයි.

## දළ විශ්ලේෂණය

- ඔබේ කාර්යය **ඔබේ බ්‍රවුසරයේ** ජීවත් වේ — පෙරනිමියෙන් රහස්‍ය, මෙම උපාංගයට බැඳී.
- ඔබේ කාර්යය ගෙනයාමට ගද්‍ය සහ උද්ධෘත **අපනයනය** කරන්න.
- නිත්‍ය **ෙරල් ගැනීම**; Browser data ඉවත් කිරීම ඔබේ කාර්යය මකා දමයි.
- අවශ්‍ය නම් ඉඩකඩ් දේශීය ෆෝල්ඩරයකට **සමමුහුර්ත** කරන්න.

## දේශීය-ප්‍රථම යනු කුමක්ද

- ලේඛන, ඉඩකඩ්, සටහන්, සහ උද්ධෘත ඔබේ බ්‍රවුසරේ දේශීය ගබඩාවේ ජීවත් වේ.
- ගිණුමක් නැත; ස්වයංක්‍රීය cloud sync නැත — පෙරනිමියෙන් රහස්‍යතාව, නමුත් ඔබේ දත්ත මෙම බ්‍රවුසරයේ, මෙම උපාංගයේ ඇත.
- ඔබේ බ්‍රවුසරේ site data ඉවත් කිරීමෙන් ඔබේ කාර්යය ඉවත් කෙරේ, ෙරල් සුරක්ෂිතව තබා ගන්න.

## අපනයනය

ඔබේ ලිවීම ගෙනයාමට හෝ ආරක්ෂිත පිටපතක් සුරැකීමට අපනයනය කරන්න. සම්පූර්ණ ඉඩකඩ් timestamp-ගත **ඉඩකඩ් සංරක්ෂිතය** (.zip) ලෙස අපනයනය කෙරේ; උද්ධෘත [BibTeX](citations-and-bibliography) ලෙස අපනයනය කෙරේ.

ඉඩකඩ් සංරක්ෂිතය ස්ථර දෙකක් අඩංගු කරයි: ඕනෑ ම ස්ථානයකදී විවෘත කළ හැකි markdown ගොනු කියවිය හැකි ගස, සහ ලේඛන, සටහන්, ඇමුණුම්, සටහන් කෙළවර, උද්ධෘත, සම්බන්ධකම්, අනුවාද ඉතිහාසය, සහ සැකසුම් ඇතුළු සෑම ලේඛනයක්ම ස්ථාපිතව ආනයනය හෝ ප්‍රතිෂ්ඨාපනය කළ හැකි සම්පූර්ණ යන්ත්‍ර-කියවිය හැකි පිටපතක්.

## ආනයනය

ඉඩකඩ් සංරක්ෂිතයකින් — නිදසුන් ඔබ බාගත් snapshot, හෝ වෙනත් උපාංගයකින් ෆෝල්ඩර-sync අපනයනයකින් — ඉඩකඩ් මෙම බ්‍රවුසරයට ගෙනෙන්න. **සැකසුම් → අපනයනය / ආනයනය** වෙත ගොස්, archive ගොනුව තෝරන්න, ඉඩකඩ් **නව ඉඩකඩ්** ලෙස ඔබේ ඇති ඒවා සමඟ ආනයනය කෙරේ. ආනයනය කිසිවක් ඉහළ ලිවීමක් නොකරයි; මෙය ඉඩකඩ් උපාංග අතර ගෙනයාමේ ක්‍රමය ද වේ.

## ෙරල්, ප්‍රතිෂ්ඨාපනය සහ සමමුහුර්ත

- ඉඩකඩ්හි backups ප්‍රදේශයෙන් **Snapshot** සාදන්න; සෑම එකක්ම ඔබ බාගත, ප්‍රතිෂ්ඨාපනය, හෝ මකා දැමිය හැකි පේළියක් එකතු කරයි.
- සම්පූර්ණ ඉඩකඩ් ඒ මොහොතට ආපසු රෝල් කිරීමට snapshot **ප්‍රතිෂ්ඨාපනය** කරන්න. වත්මන් තත්ත්වය ප්‍රතිෂ්ඨාපනයට පෙර නැවත snapshot ලෙස සුරකී, ෙබ ප්‍රතිෂ්ඨාපනයක්ම ආපසු ගත හැකිය. ප්‍රතිෂ්ඨාපන සහාය ලැබෙන්නට පෙර සාදන ලද snapshot (markdown-පමණක්) බාගත කිරීම් සඳහා පමණි.
- **බාගත** .zip සිට ප්‍රතිෂ්ඨාපනය ආනයනය මගින් ක්‍රියා කරයි — archive නව ඉඩකඩ් ලෙස ආපසු එයි, ඇති ඉඩකඩ් ස්පර්ශ නොකෙරේ.
- ඉඩකඩ් දේශීය ගබඩාවකට mirror කිරීමට **sync ෆෝල්ඩරය** සම්බන්ධ කරන්න, intervals සකසන්න, සහ ඉල්ලූ විටෙකදී sync ධාවනය කරන්න.
- ගෙදර තිරය status chip දක්වයි: sync සහ backups ස්ථාපිත නොවන ස්ථානයේ අනතුරු, sync ෆෝල්ඩරය සම්බන්ධ වූ පසු **folder sync on** ලෙස ටොගල.

ගබඩාව දේශීය, ෙබ **නිත්‍ය ෙරල් ගැනීම අත්‍යාවශ්‍ය**. Browser data ඉවත් කිරීමට, උපාංග හැරීමට, හෝ නව දෙයක් කිරීමට පෙර අපනයනය කරන්න.

## යෙදුම ආරම්භ නොවේ නම්

යෙදුමට දේශීය database විවෘත කළ නොහැකි නම්, boot error screen දිස් වේ. එතෙනිදී **Reset local data** තෝරාගත හැකි — ස්ථිර තහවුරු කිරීමකින් — යෙදුම මෙම බ්‍රවුසරයේ ගබඩා කළ සෑම දෙයක්ම මකා demo content සමඟ නැවුම් ලෙස ආරම්භ කෙරේ. ලේඛන, සටහන්, උද්ධෘත, සහ in-app ෙරල් ස්ථිරව මකා දැමෙන නිසා, ෙරල් ආරක්ෂිත ස්ථානයක ගබඩා කර, ශේෂ ලෙස පමණක් සළකන්න.

> මෙය ක්‍රියාකාරීව සංවර්ධිත pre-release යෙදුමකි. ඔබේ ෙරල් සත්‍යයේ ප්‍රභවය ලෙස සළකා නිත්‍ය ෙරල් ගන්න.
