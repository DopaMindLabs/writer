# අළුත් දේ

LIpsum Writer හි නවතම වැඩිදියුණු කිරීම්, නවතම ප්‍රථමයි. සම්පූර්ණ වෙනස් කිරීම් ලඝු-සටහන සඳහා, GitHub හිදී ව්‍යාපෘතියේ නිකුතු සටහන් බලන්න.

## 2026 ජූනි

- **දුරකථනවල Split view** — දෙකු ශ්‍රේණිය දැන් ත්‍රාසජනකව ඉහළ සහ පහළ ගොඩ ගැසෙන අතර භූ-දර්ශනයේ ලෙහෙසියෙන් තබා ඇත. [ජංගම](mobile) බලන්න.
- **ජංගමේ Doc inspector** — **තවත්** ටැබ් වෙතින් දළ සටහන, තොරතුරු, ඉතිහාසය, සහ ක්‍රියා විවෘත කරන්න. [ලේඛන පරීක්ෂකය](doc-inspector) බලන්න.
- **චාරිකා skip ගැනීම ගරු කරයි** — මඟ පෙන්වන චාරිකාවක් මාර්ගය මධ්‍යයේ ඉවත් කරන්නේ නම් චාරිකා අනෙකුත් තිරවල ස්වයංක්‍රීයව ආරම්භ කිරීම නතර කරයි. ඕනෑම චාරිකාවක් උදව් (**?**) මෙනුවෙන් නැවත ධාවනය කරන්න.
- **සමමුතිය තත්ත්වය එක් බැල්මකින්** — sync සහ backup සක්‍රීය කරන තෙක් මුල් පිටු තිරය අනතුරු chip එකක් පෙන්වයි. [ඔබේ දත්ත](your-data) බලන්න.
- **සම්බන්ධ වන්න** — **තවත්** මෙනුවෙන් අපට ළඟා වන්න; ව්‍යාපෘතියේ ලාඩ්ධිකයේ නව ප්‍රශ්නයක් විවෘත කරයි.
