# අලුත් දෑ

LIpsum Writer හි නවතම වැඩිදියුණු කිරීම්, නවතම ප්‍රථමව. සම්පූර්ණ වෙනස් දිනපොතක් සඳහා, GitHub හි ව්‍යාපෘතියේ නිකුතු සටහන් බලන්න.

## ජූනි 2026

- **දුරකථනවල Split දසුන** — දෙකොටස් දැන් සිරස් ස්ථාවරයේ ඉහළ සහ පහළ ගොඩ ගැසෙන අතර භූමිතල ස්ථාවරයේ අත්-අත දිස් වේ. [ජංගම](mobile) බලන්න.
- **ජංගමයේ ලේඛන පරීක්ෂකය** — **තවත්** ටැබ් එකෙන් ගෙනල, තොරතුරු, ඉතිහාසය, සහ ක්‍රියා විවෘත කරන්න. [ලේඛන පරීක්ෂකය](doc-inspector) බලන්න.
- **සංචාර මඟ හැරීම ගෞරව කරයි** — නිබන්ධිත සංචාරයක් මාර්ගයේදී ඉවත් කළහොත් වෙනත් තිරවලද සංචාර ස්වයංක්‍රීයව ආරම්භ වීම නතර වේ. **?** මෙනුවෙන් ඕනෑම සංචාරයක් නැවත ධාවනය කරන්න.
- **එකවර Sync තත්ත්වය** — ගෙදර තිරය sync සහ backups සක්‍රීය නොවන ස්ථානයේ අනතුරු chip එකක් දක්වයි. [ඔබේ දත්ත](your-data) බලන්න.
- **සම්බන්ධ කිරීම** — **තවත්** මෙනුවෙන් ව්‍යාපෘතියේ tracker හිදී නව ගැටළුවක් විවෘත කරන්න.
