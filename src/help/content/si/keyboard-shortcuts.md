# යතුරුපුවරු කෙටිමං

ඔබේ අත් යතුරුපුවරුවේ. macOS වලදී **⌘** භාවිතා කරන්න; Windows සහ Linux වලදී **Ctrl** භාවිතා කරන්න.

## දළ විශ්ලේෂණය

- **⌘K** — ඕනෑ ම ස්ථානයකින් ඉක්මන් උදවු විවෘත කරන්න.
- **⌘\\** — අවධාන ආකාරය ටොගල කරන්න.
- **Esc** — overlay එකක් වසන්න හෝ සංස්කරණයක් අවලංගු කරන්න.
- **Ctrl/⌘ + Enter** — ඔබ සංස්කරණය කරන උද්ධෘතය සුරකින්න.

## සාර්වත්‍රික

- **⌘K** — ඕනෑ ම ස්ථානයකින් **ඉක්මන් උදවු** overlay විවෘත කරන්න. Help Center සෙවීම හෝ කෙටිමඟකට ඇමිණෙන්න, සිවා ගෙනීමට **Esc** 누르න්න.
- **⌘\\** — [අවධාන ආකාරය](views-and-modes#focus) ස්ථාපිත සහ අක්‍රිය ටොගල කරන්න.

## සංස්කරක Markdown

රේඛාවකේ ආරම්භයේ ටයිප් කළ විට, ලිවීමේදී පරිවර්තනය වේ:

- `# ` / `## ` / `### ` — ශීර්ෂ
- `- ` / `* ` — තිත් ලැයිස්තුව
- `1. ` — ගණනය කළ ලැයිස්තුව
- `> ` — block quote

Bold සඳහා `**` හෝ italic සඳහා `*` සමඟ වචනයක් ඔතන්න.

## උද්ධෘත කවුළුව

- **Esc** — කවුළුව වසන්න (හෝ ප්‍රගතියේ ඇති සංස්කරණයක් අවලංගු කරන්න)
- **Ctrl/⌘ + Enter** — ඔබ සංස්කරණය කරන ප්‍රවේශය සුරකින්න

## බ්‍රවුසර කෙටිමං පිළිබඳ සටහනක්

යතුරු සංයෝජන කිහිපයක් ඔබේ බ්‍රවුසරය හෝ මෙහෙයුම් පද්ධතිය විසින් වෙන් කර ඇත. යෙදුම කෙටිමඟක් නිර්ණය කළ ස්ථානවලදී, ඒ ස්ථානවලදී ඉදිරියට යයි; වෙනත් ස්ථානවලදී පද්ධති පෙරනිමිය ජය ගනී.
