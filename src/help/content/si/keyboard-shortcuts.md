# යතුරුපුවරු කෙටිමං

ඔබේ අත් යතුරුපුවරුවේ තබා ගන්න. macOS හිදී **⌘** භාවිත කරන්න; Windows සහ Linux හිදී **Ctrl** භාවිත කරන්න.

## දළ විශ්ලේෂණය

- **⌘K** — ඕනෑ තැනිනුත් ඉක්මන් උදව් විවෘත කරන්න.
- **⌘\\** — අවධාන ප්‍රකාරය ටොගල් කරන්න.
- **Esc** — උඩ-ස්ථරයක් වසා දමන්න හෝ සංස්කරණයක් අවලංගු කරන්න.
- **Ctrl/⌘ + Enter** — ඔබ සංස්කරණය කරන උද්ධෘතයක් සුරකින්න.

## විශ්වීය

- **⌘K** — ඕනෑ තැනිනුත් **ඉක්මන් උදව්** උඩ-ස්ථරය විවෘත කරන්න. උදව් මධ්‍යස්ථානය සෙවීමට හෝ කෙටිමංකට යාමට, ඉන්පසු **Esc** ඔබා වසා දමන්න.
- **⌘\\** — [අවධාන ප්‍රකාරය](views-and-modes#focus) ක්‍රියාත්මක සහ අක්‍රිය කරන්න.

## සංස්කාරකයේ Markdown

පේළියක ආරම්භයේ ටයිප් කළ විට, ඒවා ලිවීමේදී áñ රූපාන්තරණය වෙයි:

- `# ` / `## ` / `### ` — සිරස්තල
- `- ` / `* ` — ලක්ෂ්‍ය ලැයිස්තුව
- `1. ` — අංකිත ලැයිස්තුව
- `> ` — කොටස් උද්ධෘතය

**bold** සඳහා `**` හෝ *italic* සඳහා `*` සමඟ වචනයක් ඔතන්න.

## උද්ධෘත තීරුව

- **Esc** — තීරුව වසා දමන්න (හෝ කරමින් ඇති සංස්කරණයක් අවලංගු කරන්න)
- **Ctrl/⌘ + Enter** — ඔබ සංස්කරණය කරන ඇතුළත් කිරීම සුරකින්න

## බ්‍රවුසර කෙටිමං පිළිබඳ සටහනක්

යතුරු සංයෝජන කිහිපයක් ඔබේ බ්‍රවුසරය හෝ මෙහෙයුම් පද්ධතිය විසින් රක්ෂා කර ඇත. යෙදුම කෙටිමංකක් නිර්ණය කරන තැන, එය ස්වකීය තිරවලදී ප්‍රමුඛතාව ගනී; නැතහොත් පද්ධති පෙරනිමිය ජය ගනී.
