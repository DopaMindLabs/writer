# Editor typography

Change the typeface and size of the editor body to suit how you like to read
and write. Set a default for every document from **Universal settings →
Typography**, and override it for any single document from the **Document
inspector**.

## At a glance

- **Universal default** — set the typeface and body size used by every document.
- **Per-document override** — change the typeface or size for a single document
  without affecting the rest.
- **Use default** — clear a document's override and inherit the universal
  default again.

## Set the universal default

Open **Universal settings → Typography**. Pick a typeface and a body size:

- **Typeface** — Serif (Source Serif 4), Sans (Geist), or Monospace (Geist Mono).
  Serif is the default and the most comfortable choice for long reads. Sans
  reads well at small sizes; Monospace is best for code-style drafts.
- **Body size** — Small, Default, Large, or Extra large. The size affects only
  the editor body; the interface and headings stay the same.

A live preview underneath the controls shows your selection.

## Override for one document

Open the **Document inspector** (the right-hand pane in the editor) and pick
**Info**. The **Editor typography** section sits below the document's
metadata. Picking a typeface or size here applies it to this document only —
other documents are unaffected.

When at least one override is set, a **Use default** button appears. Click it
to clear the override and let the document inherit the universal default
again.

## What changes — and what doesn't

The editor typography controls govern the **editor body only**. They do not
change:

- The user interface, navigation, or settings screens.
- Headings inside a document — these stay in the serif type family.
- Other reading surfaces, such as the Help Center or the document inspector
  itself.
